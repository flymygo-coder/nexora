# Установка Nexora Linux Edition в виртуальную машину

**Не относится к Nexora Kernel на собственном ядре:** Native Kernel 0.1 работает только как загружаемый прототип и не поддерживает установку или APT.

Это инструкция для предварительной сборки Nexora Linux Edition на базе Debian 13. **Пока автоматическая проверка установки Calamares не прошла, используйте исключительно новую пустую виртуальную машину.**

## Создать виртуальную машину

VirtualBox/VMware/QEMU: тип Linux (Debian 64-bit), 4 ГБ ОЗУ или больше, 2 виртуальных процессора, новый динамический виртуальный диск 40 ГБ или больше. Первый запуск для диагностики — Legacy BIOS; для UEFI нужны отдельные испытания. Не подключайте реальные физические накопители к виртуальной машине.

## Установка

1. Возьмите ISO только из **успешного** запуска GitHub Actions «Сборка установочного ISO Nexora OS». Проверьте SHA256SUMS.txt.
2. Подключите ISO как оптический носитель и запустите виртуальную машину.
3. Дождитесь загрузки рабочего стола XFCE. Откройте ярлык «Установить Nexora OS».
4. В Calamares выберите русский язык, раскладку и пустой виртуальный диск. Прочитайте экран подтверждения разметки перед установкой: выбранный диск будет перезаписан.
5. Создайте пользователя с уникальным паролем. После установки выключите VM, отключите ISO от виртуального привода и загрузитесь с виртуального диска.
6. В «Центре системы Nexora» выберите «Обновление системы» — обновления официальных пакетов Debian устанавливаются через APT после подтверждения администратора.

## Обновления

Debian-пакеты обновляются через APT с проверкой подписи репозиториев. Автоматические обновления безопасности поддерживает unattended-upgrades. **Собственные компоненты Nexora в этой предварительной сборке ещё НЕ имеют отдельного подписанного репозитория автообновлений.** Новые версии Nexora Desktop пока требуют обновления из новой проверенной сборки; нельзя считать их «самообновляющимися».

## Что пока не гарантируется

Установка на диск, UEFI, Secure Boot, драйверы видеокарт, любые Windows-игры, античиты, все сайты в РФ, полная безопасность и поддержка конкретного оборудования. Для защиты данных не используйте основной компьютер и сначала делайте снимки виртуальной машины.

## Отладка

При сбое скачайте журналы конкретного GitHub Actions run и сохраните скриншот ошибки Calamares. Не заменяйте загрузочный ISO вручную переименованным ZIP.
