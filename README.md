# Nexora OS — русскоязычная система на базе Debian 13

Это **экспериментальная** Live-система с возможностью установки на компьютер через Calamares. Включает XFCE, Firefox ESR, LibreOffice, VLC, Wine, Flatpak и графический центр приложений. Интерфейс и базовые настройки — русские.

## Сборка
GitHub → **Actions** → **Сборка установочного ISO Nexora OS** → **Run workflow**. После **успешного** выполнения доступен архив `Nexora-OS-Installer-ISO` с `Nexora_OS_Installer_amd64.iso` и SHA256SUMS.txt. **Если workflow упал, продукт не готов.** Тестирование загрузки BIOS/UEFI и установки на диск пока не автоматизировано.

## Важно
На этой стадии нет собственного ядра, фирменной полноэкранной оболочки, полной поддержки всех Windows-игр и обхода всех интернет-ограничений. **Не устанавливайте на основной диск без резервной копии.** Предпочтительна виртуальная машина с пустым диском.
